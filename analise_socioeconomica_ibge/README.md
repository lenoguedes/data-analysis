# Análise: Custo de Construção vs. Vulnerabilidade Socioeconômica

Este projeto cruza dados de duas pesquisas distintas do IBGE para entender como o custo de moradia se relaciona com a pobreza multidimensional nos estados brasileiros.

## Fontes de Dados
1.  **SINAPI (2024):** Sistema Nacional de Pesquisa de Custos e Índices da Construção Civil.
2.  **POF (2017-2018):** Pesquisa de Orçamentos Familiares - Índice de Pobreza Multidimensional (IPM-CR).

## Principais Insights
*   **Custo x Pobreza:** Estados com m² mais caros (como no Norte) enfrentam um desafio duplo, onde o custo de infraestrutura é alto em regiões de alta vulnerabilidade.
*   **Fator Financeiro:** No Nordeste, o acesso a serviços financeiros e padrão de vida é o fator que mais contribui para a pobreza (média de 20%), superando o impacto direto da moradia isolada.

## Tecnologias
*   Python para ETL (Extract, Transform, Load).
*   Pandas para manipulação de séries temporais e dados tabulares.
*   Seaborn para visualização estatística.
