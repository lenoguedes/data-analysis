## Minha Metodologia de Trabalho

Em cada projeto aqui presente, sigo o fluxo padrão de ciência de dados:
1.  **Entendimento do Problema:** Definir as perguntas de negócio ou pesquisa.
2.  **Coleta e Tratamento (ETL):** Limpeza de valores nulos, normalização e manipulação de tipos.
3.  **Análise Exploratória (EDA):** Identificação de padrões, outliers e correlações.
4.  **Visualização:** Criação de dashboards ou gráficos que facilitam a tomada de decisão.
5.  **Storytelling:** Explicação clara e objetiva dos resultados obtidos.
